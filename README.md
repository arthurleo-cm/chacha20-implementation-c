# Implementação do ChaCha20 em C

Projeto acadêmico desenvolvido com o objetivo de implementar o algoritmo de criptografia de fluxo **ChaCha20** utilizando a linguagem de programação C.

## Sobre o projeto

O ChaCha20 é um algoritmo de criptografia de fluxo utilizado para proteger informações por meio de operações matemáticas sobre dados binários.
Este projeto busca explorar os conceitos de criptografia, manipulação de bits e programação em baixo nível utilizando a linguagem C.

## Tecnologias utilizadas
- Linguagem C
- Algoritmo de criptografia ChaCha20
- Manipulação de bits e operações XOR
- Compilador GCC
## Contexto acadêmico
Projeto desenvolvido no contexto acadêmico da Pontifícia Universidade Católica de Campinas (PUC-Campinas) da matéria Projeto Integrador.
